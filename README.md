## 📑 Содержание лабораторных работ

### 1. Лабораторная работа №1
**Тема:** *Временная и частотная формы сигналов. Преобразования Фурье. Дискретизация сигналов.*

* **Стек технологий:** Python 3.x (`numpy`, `scipy.fft`, `scipy.io.wavfile`, `matplotlib`).
* **Основные задачи:**
  * Анализ гармонических сигналов во временной и частотной областях.
  * Практическое подтверждение теоремы Котельникова ($f_s \ge 2 f_{\max}$).
  * Спектральный анализ речевого сигнала (`oms1.wav`) через быстрое преобразование Фурье (БПФ / FFT).
  * Исследование эффекта децимации (downsampling) с коэффициентом $k = 10$ и возникновения наложения спектров (aliasing).
  * Моделирование $b$-битного квантования АЦП (3, 4, 5, 6 бит) для полигармонического сигнала (Вариант 5) и расчет средней ошибки квантования.

**Результаты квантования (Вариант 5):**
| Разрядность АЦП ($b$) | Уровней квантования ($2^b$) | Средняя абсолютная ошибка |
| :---: | :---: | :---: |
| 3 бита | 8 | 0.096467 |
| 4 бита | 16 | 0.046459 |
| 5 бит | 32 | 0.026506 |
| 6 бит | 64 | 0.009964 |

### 2. Лабораторная работа №2
**Тема:** *Проектирование радиопокрытия мобильных сетей. Модели распространения сигналов. Бюджеты каналов.*

* **Стек технологий:** MATLAB / GNU Octave.
* **Основные задачи:**
  * Расчет уровней шумов Найквиста, чувствительности приемников $RxSens$ БС и смартфона.
  * Расчет бюджетов каналов связи: нисходящего ($MAPL_{\text{DL}}$) и восходящего ($MAPL_{\text{UL}}$).
  * Программная реализация моделей затухания: UMiNLOS, COST 231 Hata (Dense Urban), Walfish-Ikegami (LOS / NLOS).
  * Нахождение критического радиуса соты по наихудшему направлению передачи:
    $$R = \min(d_{\text{UL}}, d_{\text{DL}})$$
  * Расчет площади 3-секторного сайта ($S_{\text{site}} = 1.95 R^2$) и расчет количества БС для внешнего покрытия ($96\text{ км}^2$) и помещений ТЦ ($4\text{ км}^2$).

**Сводка по радиопокрытию:**
* **Бюджет линии:** $MAPL_{\text{UL}} = 127.60\text{ дБ}$ против $MAPL_{\text{DL}} = 144.99\text{ дБ}$ $\rightarrow$ система строго **Uplink-limited**.
* **Макросеть (COST 231 Hata):** $R_{\text{macro}} \approx 495\text{ м}$, $S_{\text{site}} \approx 0.478\text{ км}^2$, требуется **$201\text{ сайт}$**.
* **Микросеть (UMiNLOS):** $R_{\text{micro}} \approx 475\text{ м}$, $S_{\text{site}} \approx 0.440\text{ км}^2$, требуется **$10\text{ сайтов}$**.
