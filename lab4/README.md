# Лабораторная работа №4: Изучение корреляционных свойств псевдослучайных последовательностей

Материалы выполнения лабораторной работы по дисциплине **«Основы сетей мобильной связи» (ОСМС)**: моделирование генератора последовательностей Голда на базе линейных регистров сдвига с обратными связями, расчет периодических автокорреляционных функций , взаимной корреляции и сравнительный анализ результатов в средах **C++** и **MATLAB**.

---

## 📌 Цели работы

1. Изучить принципы построения псевдослучайных двоичных последовательностей (PN-последовательностей) и их применение для синхронизации в сетях мобильной связи .
2. Реализовать на языке **C++** программную модель генератора кодов Голда на двух 5-разрядных регистрах ($N = 5$, период $p = 2^N - 1 = 31\text{ бит}$) по схеме для нечетного номера группы.
3. Рассчитать периодическую нормированную автокорреляционную функцию (АКФ) для каждой сформированной последовательности при циклических сдвигах $\tau \in [0, 31]$ по формуле:
   $$R(\tau) = \frac{C - D}{p}$$
   где $C$ — число совпадающих бит, $D$ — число различающихся бит.
4. Сформировать вторую последовательность Голда со смещенными векторами инициализации ($x_{new} = x + 1$, $y_{new} = y - 5$) и вычислить взаимную корреляцию между ними при $\tau = 0$.
5. Продублировать расчеты в среде **MATLAB**, провести сравнительный анализ с встроенной функцией `xcorr()` и построить графики отклика АКФ от величины временной задержки (lag).

## 📊 Основные результаты расчетов

### Исходные параметры варианта:
- **Номер в журнале:** $x = 5_{10} \implies [0, 0, 1, 0, 1]_2$
- **Второй регистр:** $y = x + 7 = 12_{10} \implies [0, 1, 1, 0, 0]_2$
- **Отводы обратной связи (нечетная группа):** $x_4 \oplus x_5$ и $y_2 \oplus y_5$
- **Векторы для второй последовательности:**
  - $x_{new} = 5 + 1 = 6_{10} \implies [0, 0, 1, 1, 0]_2$
  - $y_{new} = 12 - 5 = 7_{10} \implies [0, 0, 1, 1, 1]_2$

### Сформированные последовательности (31 бит):
- $\text{Gold}_1$: `1001001111001011111010110000010`
- $\text{Gold}_2$: `1000001111101100100011011110110`

### Сводные показатели корреляции:

| Показатель | Значение (C++) | Значение (MATLAB) | Примечание |
| :--- | :---: | :---: | :--- |
| **Пик АКФ $\text{Gold}_1$ ($\tau = 0, 31$)** | **$+1.00000$** | **$+1.00000$** | Точный (все 31 бит совпали) |
| **Пик АКФ $\text{Gold}_2$ ($\tau = 0, 31$)** | **$+1.00000$** | **$+1.00000$** | Точный (все 31 бит совпали) |
| **Боковые лепестки АКФ $\text{Gold}_1$** | $[-0.419; +0.226]$ | $[-0.419; +0.226]$ | Подавленный шум при $\tau \neq 0$ |
| **Боковые лепестки АКФ $\text{Gold}_2$** | $[-0.290; +0.355]$ | $[-0.290; +0.355]$ | Подавленный шум при $\tau \neq 0$ |
| **Взаимная корреляция $R_{12}(0)$** | **$+0.16129$** | **$+0.16129$** | $C = 18,\ D = 13 \implies \frac{18-13}{31}$ |

> **Вывод по корреляционным свойствам:** Последовательности Голда обладают ярко выраженным дельта-образным пиком автокорреляции при нулевом сдвиге ($R = 1.0$) и низким уровнем боковых лепестков при $\tau \neq 0$. Значение взаимной корреляции между двумя разными кодами Голда при $\tau = 0$ не превышает $0.161$, что подтверждает высокую взаимную ортогональность сигналов и позволяет использовать их для адресного разделения абонентов и надежной синхронизации в условиях многолучевости и помех.
