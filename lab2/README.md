# Лабораторная работа №2: Проектирование радиопокрытия мобильных сетей

Материалы выполнения лабораторной работы по дисциплине **«Основы сетей мобильной связи» (ОСМС)**: расчет бюджетов радиолиний (Link Budget), сравнительный анализ эмпирических моделей распространения радиосигнала и определение требуемого количества базовых станций для стандарта LTE/4G.

---

## 📌 Цели работы

1. Рассчитать бюджеты восходящего ($MAPL_{\text{UL}}$) и нисходящего ($MAPL_{\text{DL}}$) каналов связи с учетом параметров оборудования, теплового шума, запаса на интерференцию и проникновение сквозь стены.
2. Смоделировать затухание радиосигнала по трем моделям:
   - **UMiNLOS** (городские микросоты / внутри помещений);
   - **COST 231 Hata** (макросоты в плотной городской застройке);
   - **Walfish-Ikegami** (LOS и NLOS компоненты для городской застройки).
3. Определить предельный радиус действия соты по критическому направлению передачи.
4. Рассчитать площадь покрытия  БС ($S_{\text{site}} = 1.95 R^2$) и суммарное количество базовых станций для обслуживания внешней территории ($96\text{ км}^2$) и торговых центров ($4\text{ км}^2$).

## ⚙️ Требования и запуск

Для выполнения расчетов и построения графиков требуется **MATLAB** (R2019b или новее) либо свободный аналог **GNU Octave** (v6.0+).

Запуск скрипта в консоли:
```bash
octave --persist lab2.m
# или в среде MATLAB:
matlab -batch "run('lab2.m')"
```

## 📊 Основные результаты расчетов

| Параметр | Восходящий канал (UL) | Нисходящий канал (DL) |
| :--- | :---: | :---: |
| **Тепловой шум ($ThermalNoise$)** | $-104.0\text{ дБм}$ | $-101.0\text{ дБм}$ |
| **Чувствительность ($RxSens$)** | $-97.6\text{ дБм}$ | $-93.0\text{ дБм}$ |
| **Допустимые потери ($MAPL$)** | **$127.6\text{ дБ}$** | **$145.0\text{ дБ}$** |

> **Вывод по бюджету:** Радиолиния ограничена восходящим каналом , так как передатчик смартфона имеет ограниченную мощность ($24\text{ дБм}$ против $46\text{ дБм}$ у БС). Все дальнейшие оценки радиусов соты производятся по $MAPL_{\text{UL}} = 127.6\text{ дБ}$.

### Итоговое покрытие территории:

* **Макросеть (COST 231 Hata, внешняя территория $96\text{ км}^2$):**
  - Радиус соты: $R \approx 495\text{ м}$
  - Площадь покрытия сайта: $S_{\text{site}} \approx 0.478\text{ км}^2$
  - Количество сайтов: **$201\text{ шт.}$**
* **Микросеть (UMiNLOS, ТЦ/БЦ $4\text{ км}^2$):**
  - Радиус соты: $R \approx 475\text{ м}$
  - Площадь покрытия сайта: $S_{\text{site}} \approx 0.440\text{ км}^2$
  - Количество сайтов: **$10\text{ шт.}$**
